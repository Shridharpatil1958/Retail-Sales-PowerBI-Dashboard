# 🧠 Advanced DAX Features

```DAX
Revenue Growth % =
DIVIDE(
    [Current Revenue] - [Previous Revenue],
    [Previous Revenue]
)
```

```DAX
Profit Margin % =
DIVIDE(
    [Total Profit],
    [Total Revenue]
)
```

```DAX
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Transactions]
)
```
